## P3803 多项式乘法

### 其实就是我们暴力计算DFT每个系数都是On，合起来是N*N的，（然后FFT可以变成nlog好像是一位学者证明出来的 之前说是两个log来着？）。核心就是一句话：因为复变的单位根有周期性，所以我们可以通过两个长度为n的区间合并出一个长度为2*n区间的变换后的系数。

今天把 FFT 模板重新梳理了一遍。这个东西第一次看确实有点抽象，但如果只从做题视角出发，其实可以先抓住一句话：

```text
FFT 是用 O(n log n) 的复杂度计算多项式卷积。
```

对于两个多项式：

$$
A(x)=\sum_i a_i x^i,\qquad B(x)=\sum_i b_i x^i
$$

它们的乘积：

$$
C(x)=A(x)B(x)
$$

其中第 $k$ 项系数是：

$$
c_k=\sum_{i+j=k} a_i b_j
$$

这个式子本质上就是卷积。朴素做法枚举 $i,j$，复杂度是 $O(nm)$；FFT 的目标就是把这个过程优化到 $O(n\log n)$。

## 核心思想

多项式有两种常见表示：

- **系数表示**：直接存 $a_0,a_1,\dots,a_n$。
- **点值表示**：取很多个点 $x_i$，存 $(x_i,A(x_i))$。

系数表示下，乘法很慢；点值表示下，乘法很简单：

$$
C(x_i)=A(x_i)B(x_i)
$$

所以 FFT 的流程就是：

```text
系数表示 -> 点值表示 -> 逐点相乘 -> 系数表示
```

对应到代码里就是：

```cpp
fft(fa, false);
fft(fb, false);

for (int i = 0; i < n; i++) {
    fa[i] *= fb[i];
}

fft(fa, true);
```

## 长度为什么要补成 2 的幂

如果 $A$ 的长度是 $n$，$B$ 的长度是 $m$，那么乘积长度是：

$$
n+m-1
$$

FFT 的迭代写法要求长度是 $2$ 的幂，所以代码里要把长度扩展到不小于 `need` 的最小 $2$ 的幂：

```cpp
int need = A.size() + B.size() - 1;
int n = 1;
while (n < need) n <<= 1;

fa.resize(n);
fb.resize(n);
```

补出来的位置系数都是 $0$，不会影响最终答案。

## 位逆序置换

迭代版 FFT 开始前要做一次位逆序置换，也就是把下标按照二进制反转后的顺序重排。

比如 $n=8$ 时：

```text
0(000) -> 0(000)
1(001) -> 4(100)
2(010) -> 2(010)
3(011) -> 6(110)
```

对应模板里这段：

```cpp
for (int i = 1, j = 0; i < n; i++) {
    int bit = n >> 1;
    while (j & bit) {
        j ^= bit;
        bit >>= 1;
    }
    j ^= bit;

    if (i < j) swap(a[i], a[j]);
}
```

这一步看起来比较玄学，但它的作用很直接：提前把数组排成适合从长度 $2,4,8,\dots$ 逐层合并的顺序。

## 蝴蝶合并

FFT 的合并过程可以理解成不断把两个小多项式合成一个大多项式。

每一层的区间长度是 `len`，单位根为：

$$
\omega_{\text{len}}=e^{\frac{2\pi i}{\text{len}}}
$$

代码里用复数表示：

```cpp
double ang = 2 * pi / len;
if (invert) ang = -ang;
cd wn(cos(ang), sin(ang));
```

蝴蝶操作是：

$$
u=a_{i+j},\qquad v=a_{i+j+\frac{len}{2}}\cdot w
$$

合并后：

$$
a_{i+j}=u+v
$$

$$
a_{i+j+\frac{len}{2}}=u-v
$$

对应代码：

```cpp
cd u = a[i + j];
cd v = a[i + j + len / 2] * w;

a[i + j] = u + v;
a[i + j + len / 2] = u - v;

w *= wn;
```

这一段就是 FFT 模板真正的核心。

## 正变换和逆变换

模板里用 `invert` 区分正变换和逆变换：

- `invert == false`：FFT，把系数表示变成点值表示。
- `invert == true`：IFFT，把点值表示变回系数表示。

逆变换时单位根方向相反，最后还要把每一项除以 $n$：

```cpp
if (invert) {
    for (cd& x : a) {
        x /= n;
    }
}
```

这个除以 $n$ 是不能忘的，不然结果会整体放大 $n$ 倍。

## 精度处理

FFT 里用的是 `complex<double>`，所以最后得到的实部理论上是整数，但实际可能会有浮点误差。

例如本来应该是 $3$，计算出来可能是：

```text
2.999999999
3.000000001
```

所以模板里用 `llround` 四舍五入：

```cpp
for (int i = 0; i < need; i++) {
    C[i] = llround(fa[i].real());
}
```

P3803 这种模板题这样写就够了。如果系数范围更大，或者需要取模，就要考虑 NTT 或者拆系数的写法。

## 完整流程

整个 `multiply` 可以记成：

```text
1. 把 A、B 转成复数数组。
2. 计算答案长度 need = n + m - 1。
3. 把 FFT 长度扩成 2 的幂。
4. 对 A、B 分别做 FFT。
5. 点值逐项相乘。
6. 做 IFFT。
7. 四舍五入取回整数系数。
```

复杂度：

$$
O(n\log n)
$$

其中这里的 $n$ 是补齐后的 $2$ 的幂长度。

## 小结

这份模板最值得记的几个点：

- 多项式乘法本质是卷积。
- FFT 把系数表示转成点值表示。
- 点值表示下乘法就是逐点相乘。
- 迭代版 FFT 要先做位逆序置换。
- 蝴蝶合并是核心。
- IFFT 最后要除以 $n$。
- `double` 会有误差，最后要 `llround`。

写完再看，其实 FFT 不是“强行背公式”，而是把卷积换了一个更适合计算的表示方式。

## B. Alternating String

题目要判断一个只含 `a` 和 `b` 的字符串，能不能通过至多一次操作变成任意交替串。一次操作是选择一个子串，可以选择是否把 `a/b` 全部翻转，然后一定要把这个子串反转。

交替串只有两种形态：

```text
ababab...
bababa...
```

所以代码里的做法是先构造出这两个目标串，然后分别记录哪些位置不一样。

关键观察是：如果相对某一个目标串，所有“不一样的位置”只形成一段连续区间，那么这一段就可以通过一次操作处理掉；如果不匹配的位置分成了很多段，就没法一次完成。

代码里 `flag1` 和 `flag2` 初始都是 `2`，每遇到一个新的不匹配段就减一。最后只要有一种目标串还能剩下至少 `1`，说明不匹配段数不超过 `1`，答案就是 `YES`。

```cpp
#include <bits/stdc++.h>
typedef long long ll;
typedef long double db;
const ll mod=1e9+7;
const db pi=acos(-1);
const db eps=1e-10;
const int maxn=3e5;
const int inf=1e8;
const ll INF=1e17;
using namespace std;
string s;
int n;
void slove(){
    cin>>s;
    n=int(s.length());
    vector<bool>A(n+1,0),B(n+1,0);
    string a(n, 'a');
    string b(n, 'b');
    for(int i = 1; i < n; i += 2) {
        a[i] = 'b';
        b[i] = 'a';
    }
    for(int i=0;i<n;i++){
        if(s[i]!=a[i]) A[i+1]=1;
        if(s[i]!=b[i]) B[i+1]=1;
    }
    int flag1=2;int flag2=2;
    for(int i=1;i<=n;i++) {
        if(A[i]==1 && A[i-1]==0) {
            flag1--;
        }
        if(B[i]==1 && B[i-1]==0) {
            flag2--;
        }
    }
    if(flag1>=1 or flag2>=1) cout<<"YES";
    else cout<<"NO";
    return;
}
int main(){
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);
    int t=1;
    cin>>t;
    while(t--){
        slove();
        cout<<"\n";
    }
    return (0-0);
}
```

复杂度是 $O(n)$。

## C. Red-Black Pairs

题目给一个 $2\times n$ 的表格，每个格子是 `R` 或 `B`。现在要重涂尽量少的格子，使所有格子能被划分成 $n$ 对，并且每一对相邻、同色。

每一列只有两种处理方式：

- 竖着配对：第 $i$ 列上下两个格子配成一对，代价是 `S[i] != F[i]`。
- 横着配对：第 $i$、$i+1$ 两列上下分别横着配，代价是 `F[i] != F[i+1]` 加上 `S[i] != S[i+1]`。

所以本质上是一个很短的 DP：

$$
dp_{i+1}=\min(dp_{i+1},dp_i+\text{vertical cost})
$$

$$
dp_{i+2}=\min(dp_{i+2},dp_i+\text{horizontal cost})
$$

我这份代码没有显式写 `dp`，而是把几种局部情况压成了贪心判断：

- 当前上下已经相等，直接竖着配，不增加答案。
- 当前上下不等，但下一列上下相等，那当前列单独改一次。
- 当前和下一列上下都不等，如果上下两行各自能横着配好，就跳过两列。
- 其他情况就至少要改一次。

```cpp
#include <bits/stdc++.h>
typedef long long ll;
typedef long double db;
const ll mod=1e9+7;
const db pi=acos(-1);
const db eps=1e-10;
const int maxn=3e5;
const int inf=1e8;
const ll INF=1e17;
using namespace std;
int n;
string S,F;
void slove(){
    cin>>n;
    int ans=0;
    cin>>F>>S;
    S+="R";
    F+="R";
    for(int i=0;i<n;i++){
        if(S[i]==F[i]) continue;
        else{
            if(S[i+1]==F[i+1]) {
                ans++;
                continue;
            }
            else{
                if(F[i]==F[i+1] &&S[i]==S[i+1]){
                    i++;
                }
                else {
                    ans++;
                }
            }
        }
    }
    cout<<ans<<"\n";
    return;
}
int main(){
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);
    int t=1;
    cin>>t;
    while(t--){
        slove();
    }
    return (0-0);
}
```

复杂度是 $O(n)$。

## D. Exceptional Segments

题目给 $n$ 和 $x$，要数有多少个区间 $[l,r]$ 满足：

$$
1\le l\le x\le r\le n
$$

并且：

$$
l\oplus(l+1)\oplus\dots\oplus r=0
$$

经典处理方式是用前缀异或：

$$
pre_i=1\oplus2\oplus\dots\oplus i
$$

那么区间异或为：

$$
pre_r\oplus pre_{l-1}
$$

要让它等于 $0$，就要满足：

$$
pre_r=pre_{l-1}
$$

也就是说，我们要在左边选一个 $l-1$，在右边选一个 $r$，让它们的前缀异或值相同。

前缀异或有固定周期：

$$
pre_i=
\begin{cases}
i,&i\bmod4=0\\
1,&i\bmod4=1\\
i+1,&i\bmod4=2\\
0,&i\bmod4=3
\end{cases}
$$

因为 $l-1<x\le r$，真正能重复出现并产生贡献的只有前缀值 $0$ 和 $1$。所以答案就是：

```text
左边 pre=0 的数量 * 右边 pre=0 的数量
+
左边 pre=1 的数量 * 右边 pre=1 的数量
```

代码里没有直接写 `count0/count1`，而是按 $x$ 的奇偶把这些数量拆成了四个式子。`cal(l,r)` 实际上就是计算两边数量相乘：

$$
(l+1)(r+1)
$$

最后对 $998244353$ 取模。

```cpp
#include <bits/stdc++.h>
typedef long long ll;
typedef long double db;
const ll mod=998244353;
const db pi=acos(-1);
const db eps=1e-10;
const int maxn=3e5;
const int inf=1e8;
const ll INF=1e17;
using namespace std;
ll n,x;
ll cal(ll l , ll r ){
    return (((l+1)%mod)*((r+1)%mod))%mod;
}
void slove(){
    ll ans=0;
    cin>>n>>x;
    if(x%2==1) {
        ll lef = (x-1)/4 ;
        ll rig = max((n-(x+2)),0ll)/4;
        if( n>=x+2 && x>=1 ) ans = ans + cal(lef,rig);
        ans%=mod;
        lef = (x-3)/4;
        rig = max(0ll, (n-(x)))/4;
        if( n>=x  && x>=3)  ans = ans + cal(lef,rig);
    }
    else{
        ll lef = (x)/4 ;
        ll rig = max((n-(x+3)),0ll)/4;
        if( n>=x+3 ) ans = ans + cal(lef,rig);
        ans%=mod;
        lef = (x-2)/4;
        rig = max(0ll, (n-(x+1)))/4;
        if( n>=x+1 && x>=2) ans = ans + cal(lef,rig);
    }
    cout << (ans+mod)%mod;
    return;
}
int main(){
    ios::sync_with_stdio(0);
    cin.tie(0);
    cout.tie(0);
    int t=1;
    cin>>t;
    while(t--){
        slove();
        cout<<"\n";
    }
    return (0-0);
}
```

复杂度是 $O(1)$ 每组数据。
