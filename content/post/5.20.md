# 汇总一下CSES图论题

## IC2026 invation南昌 C题

给定一张有向图，图中有 `n` 个点和 `m` 条初始有向边。每条边的长度都是 `1`。

初始边在第 `0` 天就已经存在。

之后有 `k` 天，每天会新建一条有向边 `x -> y`。新建边可能是：

- 已经存在的边；
- 自环，也就是 `x == y`。

现在有 `q` 个询问，每个询问给出起点 `s` 和终点 `t`，并给定一个统一的目标距离 `w`。

对于每个询问，需要回答：

> 最早在哪一天之后，存在一条从 `s` 到 `t` 的有向游走，使得恰好走 `w` 条边？

这里“游走”允许重复经过点和边。

如果初始图中就能满足，答案是 `0`。如果所有边都建完后仍然无法满足，输出 `-1`。

> 首先结合数据范围应该考虑到矩阵乘法，也就是走过一条边就是矩阵相乘一次。

> 本题求的是 最早从哪天起来，也就是所有s-t路径中每条路径中最大值的最小值

> 所以维护一个min(max*)矩阵就好了

# 21沈阳regional B：最小异或和

给定一个长度为 `n` 的非负整数序列：

\[
a_1, a_2, \dots, a_n
\]

同时给出 `m` 条限制条件，每条限制形如：

\[
a_u \oplus a_v = w
\]

其中 `⊕` 表示按位异或。

你的任务是：在所有满足这些限制条件的序列中，找到元素总和

\[
a_1 + a_2 + \dots + a_n
\]

的最小值。

如果不存在任何满足条件的序列，输出 `-1`。

---

## 输入格式

第一行包含两个整数 `n` 和 `m`，表示序列长度和限制条件数量。

接下来 `m` 行，每行包含三个整数 `u`、`v`、`w`，表示：

\[
a_u \oplus a_v = w
\]

---

## 输出格式

输出一个整数，表示满足所有条件时的最小元素总和。

如果无解，输出 `-1`。

---

## 数据范围

- \(1 \le n \le 10^5\)
- \(0 \le m \le 2 \times 10^5\)
- \(1 \le u, v \le n\)
- \(0 \le w < 2^{30}\)

---

## 示例说明

异或运算会比较两个数二进制下的每一位：

- 相同为 `0`
- 不同为 `1`

例如：

\[
109 \oplus 41 = 68
\]

### 做法1 ：这种异或的问题考虑拆位，本题显然是可以拆位的。拆位后独立计算1-n如何最小就是说取最少的1.

- 考虑：连边实际上可以看成是连通块(这里可以看作是一个特殊的二分图，二分图可以认为是边权一直为1的一个异或要求)
- 一个比较显然的结论是：在一个连通块内我们只要确定一个root的val，就可以遍历得到所有数值的解(前提有解)
- 于是直接DFS就好了，DFS记录一下root取1的时候 连通块内1的数量 选0的时候所有取值反过来。
- 注意实现细节。

### 做法2 ： 带权并查集

- 核心就是维护每个联通块内部，每个点到root的相对异或数值
- 最后统计每个连通块中每位相对root的1的数量，也需要拆位计算

# CSES Graph Algorithms 查漏

> 题单参考：[CSES Problem Set](https://cses.fi/problemset/list/) 的 Graph Algorithms。

## Counting Rooms / Labyrinth / Message Route

- `Counting Rooms`：网格 DFS/BFS，统计 `.` 的连通块数量。
- `Labyrinth`：网格 BFS，记录前驱方向，最后从终点倒推路径。
- `Message Route`：无权图最短路，BFS + `pre` 数组输出路径。

## Building Roads / Building Teams / Round Trip

- `Building Roads`：找无向图连通块，每个块拿一个代表点，最后连成一条链。
- `Building Teams`：二分图染色，遇到同色相邻就 `IMPOSSIBLE`。
- `Round Trip`：无向图 DFS 找环，注意用父节点避免把返边当成来边。

## Monsters

- 多源 BFS 先算怪物到每个格子的最早时间。
- 人再 BFS，只能走到 `person_time < monster_time` 的格子。
- 一旦走到边界就可以倒推路径。

## Shortest Routes / Flight Discount / Flight Routes

- `Shortest Routes I`：单源最短路，Dijkstra 板题。
- `Shortest Routes II`：点数小，多源询问，Floyd。
- `Flight Discount`：把点拆成两层，第一层没用优惠，第二层已经用过优惠。
- `Flight Routes`：求前 `k` 短路，堆里按距离扩展，每个点最多弹出 `k` 次。

## High Score / Cycle Finding

- `High Score`：最长路可以把边权取负，然后判能影响 `1 -> n` 的负环。
- `Cycle Finding`：加超级源跑 Bellman/SPFA，出现第 `n` 轮松弛就能倒前驱找负环。

## Round Trip II / Flight Routes Check

- `Round Trip II`：有向图找环，用 DFS 栈或者三色标记。
- `Flight Routes Check`：判断强连通。可以 Tarjan，也可以正反图从 1 各 DFS 一遍。

## Mail Delivery / Teleporters Path / De Bruijn Sequence

- `Mail Delivery`：无向欧拉回路，所有点度数为偶数，并且有边的点连通。
- `Teleporters Path`：有向欧拉路径，要求 `1` 出度比入度多 1，`n` 入度比出度多 1。
- `De Bruijn Sequence`：把长度 `n-1` 的二进制串当点，转移加 `0/1` 当边，本质还是欧拉回路。

## Knight's Tour

- 骑士巡游用 DFS 回溯。
- 常用 Warnsdorff：每次优先走后续可走位置最少的点，速度会稳很多。

## Police Chase / School Dance / Distinct Routes

- `Police Chase`：最小割，边容量全是 1，最大流后在残量网络里找割边。
- `School Dance`：二分图最大匹配，可以 Dinic，也可以匈牙利。
- `Distinct Routes`：边不相交路径条数，单位容量最大流，最后沿满流边把路径拆出来。
