## 线性基的直觉

线性基可以理解成：用尽量少的一组“独立方向”，表示原来一堆对象能组合出来的所有结果。

在线性代数里，对象是实数向量，组合方式是实数线性组合；在算法竞赛里说“线性基”，很多时候特指异或线性基：

```text
对象：整数的二进制 01 向量
组合：异或
所在域：GF(2)
```

一个 64 位整数可以看成 64 维 01 向量。比如：

```text
13 = 1101 = 1000 xor 0100 xor 0001
```

这就和线性空间里的标准基很像：

```text
0001, 0010, 0100, 1000, ...
```

不过竞赛中的线性基不是直接拿标准基，而是从题目给的一堆数里提取出一组等价的基。它能表示的不是整个 $2^{64}$ 空间，而是原数组所有子集异或能得到的空间。

更具体地说，如果给了 $n$ 个数，我们希望维护一个集合，使得：

- 这个集合里的数线性无关。
- 原来所有数能异或出来的结果，新集合也都能异或出来。
- 集合大小尽量小，最多也就 `LOG + 1` 个。

这件事本质上就是异或版高斯消元。

## 插入：异或版高斯消元

维护 `base[i]` 表示最高位是 `i` 的基向量。插入一个数 `x` 时，从高位往低位扫：

- 如果 `x` 的第 `i` 位不是 `1`，跳过。
- 如果 `base[i]` 为空，说明出现了新的独立方向，把 `x` 放进去。
- 如果 `base[i]` 已经存在，就用 `x ^= base[i]` 消掉这一位。

如果最后 `x` 被消成了 `0`，说明它可以被已有基表示，插入失败。

```cpp
struct LinearBasis {
    static const int LOG = 62;
    long long base[LOG + 1]{};

    bool insert(long long x) {
        for (int i = LOG; i >= 0; i--) {
            if (((x >> i) & 1) == 0) continue;

            if (!base[i]) {
                base[i] = x;
                return true;
            }

            x ^= base[i];
        }
        return false;
    }

    long long query_max() const {
        long long ans = 0;
        for (int i = LOG; i >= 0; i--) {
            if ((ans ^ base[i]) > ans) ans ^= base[i];
        }
        return ans;
    }

    long long maximize(long long x) const {
        for (int i = LOG; i >= 0; i--) {
            if ((x ^ base[i]) > x) x ^= base[i];
        }
        return x;
    }

    long long minimize(long long x) const {
        for (int i = LOG; i >= 0; i--) {
            if (base[i] && (x ^ base[i]) < x) x ^= base[i];
        }
        return x;
    }

    bool can_make(long long x) const {
        for (int i = LOG; i >= 0; i--) {
            if (((x >> i) & 1) == 0) continue;
            if (!base[i]) return false;
            x ^= base[i];
        }
        return true;
    }
};
```

这里最重要的不是背代码，而是记住两个含义：

- `insert(x) == true`：`x` 提供了新的独立方向。
- `insert(x) == false`：`x` 已经能被之前的数异或出来。

## 最大值、最小值和可表示性

线性基查询最大值的时候，从高位往低位贪心。原因很简单：二进制大小由最高不同位决定。

如果 `ans ^ base[i]` 更大，就说明异或这个基向量能把当前答案变优，于是直接异或。

最小化也是同理：

```text
如果 val ^ base[i] 更小，就异或。
```

判断一个数 `x` 能不能被表示出来，也和插入过程一样：用已有基不断消元，如果能消成 `0`，说明可表示；如果某一位需要消但没有对应基，就不可表示。

另外一个常用结论：

> $n$ 个数的线性基秩为 $r$，则可以表示出的不同异或值有 $2^r$ 个。若某个值 $x$ 可表示，则异或和为 $x$ 的子集数量是 $2^{n-r}$；否则数量是 $0$。

这个结论在计数题里很常见。

## 最大权线性无关集

有一类题的共同模型是：

```text
从一堆向量里选一个线性无关集合，同时让权值最大或费用最小。
```

这和 Kruskal 很像。

| Kruskal 最小生成树 | 线性无关集问题       |
| ------------------ | -------------------- |
| 边                 | 向量 / 数            |
| 边权               | 费用 / 价值          |
| 加边不成环就选     | 插入线性基成功就选   |
| 并查集判断成环     | 高斯消元判断线性相关 |

### P3265 装备购买

这题是实数域线性基。每件装备是一个 $m$ 维实数向量，如果它能被已经买的装备线性表示出来，就没有必要买。

目标是在买下最多装备的前提下，总费用最小，所以做法是：

```text
按费用升序排序 -> 能插入实数线性基就买
```

它本质上就是“最小费用最大线性无关组”。

实数域要注意 `eps`，不能直接判断 `== 0`：

```cpp
const long double eps = 1e-10;
vector<long double> basis[505];
bool has_basis[505];
int m;

bool insert_real_basis(vector<long double> v) {
    for (int i = 0; i < m; i++) {
        if (fabsl(v[i]) < eps) continue;

        if (!has_basis[i]) {
            has_basis[i] = true;
            long double div = v[i];
            for (int j = i; j < m; j++) v[j] /= div;
            basis[i] = v;
            return true;
        }

        long double k = v[i] / basis[i][i];
        for (int j = i; j < m; j++) {
            v[j] -= k * basis[i][j];
        }
    }
    return false;
}
```

### P4570 元素

这题是异或域版本。题意里的限制可以翻译成：

```text
选出的元素编号不能存在非空子集异或为 0。
```

这等价于选出的编号在线性基意义下线性无关。

目标是最大化魔力值，所以：

```text
按魔力值降序排序 -> 能插入异或线性基就选
```

### P4301 新 Nim 游戏

新 Nim 的关键是：第一回合先手删除若干堆之后，要让留下来的集合满足任意非空子集异或和都不为 `0`。

也就是说，留下来的堆必须线性无关。

先手想删除的总数最小，等价于保留的总数最大：

```text
按堆大小降序排序 -> 能插入就保留 -> 答案 = 总和 - 保留和
```

这三个题可以放在一起记：

| 题目           | 域     | 排序方式   | 选择标准       |

| P3265 装备购买 | 实数域 | 费用升序   | 插入成功就买   |
| P4570 元素     | 异或域 | 权值降序   | 插入成功就选   |
| P4301 新 Nim   | 异或域 | 堆大小降序 | 插入成功就保留 |

## 图上最大 XOR 路径

P4151 最大 XOR 和路径是线性基在图上的经典应用。

如果图是一棵树，从 `1` 到 `n` 的路径唯一，答案就是这条路径边权异或和。问题出在有环。

题目允许路径重复经过点和边，所以可以在某条 `1 -> n` 路径上绕环。绕一个环，相当于让路径异或和额外异或上这个环的异或值。

因此：

```text
任意一条 1 到 n 的路径 XOR
= 某条固定路径 dis[n] xor 若干个环的 XOR
```

环的异或值可以这样求。先 DFS/BFS 随便定一个 `dis[x]`，表示从 `1` 到 `x` 的某条路径异或和。对任意边 `(u, v, w)`：

$$
cycle = dis[u] \oplus dis[v] \oplus w
$$

把所有 `cycle` 插入线性基，最后用这些环去最大化 `dis[n]`。

```cpp
void dfs(int start) {
    stack<int> st;
    st.push(start);
    vis[start] = true;
    dis[start] = 0;

    while (!st.empty()) {
        int x = st.top();
        st.pop();
        for (auto [to, w] : g[x]) {
            if (!vis[to]) {
                vis[to] = true;
                dis[to] = dis[x] ^ w;
                st.push(to);
            }
        }
    }
}

for (auto [u, v, w] : edges) {
    long long cycle = dis[u] ^ dis[v] ^ w;
    basis.insert(cycle);
}

cout << basis.maximize(dis[n]) << "\n";
```

这里的 `dis` 不是最短路，只是 DFS 树上随便找出来的一条路径异或值。

## CCPC Online 2024 J 的思路

这个题稍微绕一点，但核心还是线性基。

设：

$$
A = a_1 \oplus a_2 \oplus \cdots \oplus a_n
$$

$$
B = b_1 \oplus b_2 \oplus \cdots \oplus b_n
$$

交换第 $i$ 个位置的 $a_i$ 和 $b_i$ 时，两个总异或值都会异或上：

$$
c_i = a_i \oplus b_i
$$

所以交换若干位置，本质上是从所有 $c_i$ 张成的线性空间里选一个 $x$，然后：

```text
A' = A xor x
B' = B xor x
目标：minimize max(A', B')
```

注意一个不变量：

$$
(A \oplus x) \oplus (B \oplus x) = A \oplus B
$$

令 $D=A\oplus B$。

- 如果 $D=0$，说明两个数最后始终相等，直接用线性基最小化 `A ^ x`。
- 如果 $D\ne 0$，设 `k` 是 $D$ 的最高位 `1`。最终 `A ^ x` 和 `B ^ x` 在第 `k` 位一定一个是 `0`、一个是 `1`，第 `k` 位为 `1` 的那个必然更大。

于是可以分两种情况：

```text
让 A ^ x 的第 k 位为 1，并最小化 A ^ x
让 B ^ x 的第 k 位为 1，并最小化 B ^ x
```

子问题是：在线性空间里选一个 `x`，使得 `(P ^ x)` 的第 `k` 位固定为 `1`，并让它尽量小。

做法是找一个第 `k` 位为 `1` 的 `special` 向量：

- 如果必须让 `x` 的第 `k` 位为 `1`，就先异或 `special`。
- 其他第 `k` 位为 `1` 的向量都可以异或 `special`，变成第 `k` 位为 `0` 的向量。
- 之后重新建一个只影响低位的线性基，再对当前值做 `minimize`。

这个题的关键不在模板，而在建模：

```text
交换若干位置 = A 和 B 同时 xor 一个来自线性空间的 x。
```

## ABC429 F：线段树维护矩阵转移

这题不是线性基，但这几天也写了，所以顺手记一下。

题意大概是：一个 $3\times n$ 的网格，每次翻转一个格子，询问从 `(1,1)` 到 `(3,n)` 的最短路。`n,q` 都很大，不能每次 BFS。

核心观察是：最短路径可以看成基本不往左走，横向移动次数固定是 $n-1$，真正需要维护的是竖向移动次数。

每一列只有 3 个格子，所以可以把一列压成一个 $3\times3$ 转移矩阵：

```text
mat[out][in] = 从这一列的 in 行进入，到 out 行出去，需要的最小竖向移动次数
```

如果一列全空，矩阵就是：

```text
0 1 2
1 0 1
2 1 0
```

如果中间有墙，比如 `.#.`，那么第 1 行和第 3 行在这一列内部就不互通。

区间合并时做 min-plus 矩阵乘法：

$$
C[out][in] = \min_{mid}(A[mid][in] + B[out][mid])
$$

因为这个合并满足结合律，所以可以用线段树维护。单点翻转只影响一列，更新一列矩阵即可。

```cpp
struct Info {
    long long mat[3][3];
};

Info merge(const Info& L, const Info& R) {
    Info C;
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            C.mat[i][j] = INF;
        }
    }

    for (int out = 0; out < 3; out++) {
        for (int in = 0; in < 3; in++) {
            for (int mid = 0; mid < 3; mid++) {
                C.mat[out][in] = min(C.mat[out][in],
                                     L.mat[mid][in] + R.mat[out][mid]);
            }
        }
    }
    return C;
}
```

容易写错的地方：

- 线段树维护的是列，不是格子。
- `modify` 的下标应该是 `column`。
- 线段树数组开 `4 * n`。
- 矩阵只统计竖向代价，最后答案还要加上横向的 `n - 1`。
- `mat[out][in]` 和 `mat[from][to]` 二选一，合并公式要和定义一致。

## 题眼总结

| 题面信号                 | 应该想到          | 常用操作                     |
| ------------------------ | ----------------- | ---------------------------- |
| 任选若干数异或最大       | 异或线性基        | `insert + query_max`       |
| 判断能不能异或出 `x`   | 张成空间判断      | `can_make(x)`              |
| 存在非空子集异或为 `0` | 线性相关          | `insert` 失败              |
| 最大权线性无关集合       | 拟阵贪心          | 按权值降序，能插入就选       |
| 最小费用基               | 拟阵贪心          | 按费用升序，能插入就选       |
| 图上路径 XOR 最大        | 环空间 + 线性基   | `dis[u] ^ dis[v] ^ w` 建基 |
| 小宽度网格动态最短路     | 矩阵转移 + 线段树 | min-plus 合并                |

## 常见坑

- `LOG` 要开够。$10^{18}$ 大约 60 位，通常开到 62 比较稳。
- `insert` 失败不是代码错，而是说明这个数已经可表示。
- 最大权线性无关集不是先建完基再挑权值，而是先排序，再边扫边插入。
- 实数域高斯消元要用 `eps`。
- 图上 XOR 路径里的 `dis` 不是最短路。
- 线性基最小化和最大化都要从高位往低位贪心。
- CCPC J 这种题要先找不变量：`A ^ B` 不变。
