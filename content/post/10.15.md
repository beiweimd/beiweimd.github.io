## G题

我们只要注意到，$\gcd=k$ 的 subset 只有 $k$ 以及 $(2k,3k)$、$(4k,5k)$ 之类的组合，所以先这样组合，然后求出剩下没有参与组合的数。

对于这些数字，直接修改成 $k$ 是更明智的，当然我们需要特判 $n<k$ 的情况。

随后，没有参与组合的数修改完后，若 $m$ 还没有用完，此时两个 $m$ 的修改可以使答案 $+1$。

## A题：A Lot of Paintings

题目链接：[QOJ 14706 — A Lot of Paintings](https://qoj.ac/problem/14706)。

### 题意

给出每个人提交画作数量占总数的百分比，百分比已经四舍五入成整数。要求构造一组非负整数 $b_i$，使得总数大于 $0$，并且各项占比四舍五入后与输入一致；无解则输出 No。

下文用 $a_i$ 表示代码读入的整数百分比，即题面中的 $d_i$。

### 把四舍五入转化成区间

设真实百分比为 $p_i$。四舍五入得到 $a_i$，意味着：

$$
a_i-\frac12\le p_i<a_i+\frac12.
$$

同时 $p_i\ge0$。为消掉 $0.5$，令 $x_i=2p_i$，便得到：

$$
l_i=\max(2a_i-1,0),\qquad r_i=2a_i+1,
$$

$$
l_i\le x_i<r_i,\qquad \sum_{i=1}^{n}x_i=200.
$$

注意这里是**左闭右开**。例如真实百分比为 $25.5\%$ 时，会被舍入成 $26\%$，不能算作 $25\%$。

### 先判断有没有解

记：

$$
L=\sum_{i=1}^{n}l_i,\qquad R=\sum_{i=1}^{n}r_i.
$$

所有数都取下界时，总和最小，为 $L$；所有数都向右端点靠近时，总和可以趋近 $R$，但不能达到 $R$。

因此，有解的充要条件是：

$$
L\le200<R.
$$

对应代码：当 lef > 200 或 rig <= 200 时，输出 No。

其中 $L=200$ 可以直接全部取下界；$R=200$ 则不行，因为每个右端点都不能取。

### 按相同比例填充每个区间

现在全部取下界，总和还差：

$$
D=200-L.
$$

所有区间的总长度为：

$$
W=\sum_{i=1}^{n}(r_i-l_i)=R-L.
$$

它就是代码中的 diff。由于已经通过有解判断：

$$
0\le D<W,\qquad 0\le\frac DW<1.
$$

我们让每个数都走完自己区间长度的 $\frac DW$，也就是构造：

$$
x_i=l_i+(r_i-l_i)\frac DW.
$$

这样不需要逐个贪心分配。区间越长，分配到的差额就越多。

一方面，$\frac DW\in[0,1)$，所以每个 $x_i$ 都满足 $l_i\le x_i<r_i$，不会碰到不能取的右端点。

另一方面：

$$
\sum_{i=1}^{n}x_i
=L+\frac DW\sum_{i=1}^{n}(r_i-l_i)
=L+D
=200.
$$

所以这组实数已经满足要求。

### 为什么直接输出分子即可

题目要求输出整数，而上面的 $x_i$ 可能是分数。把它们统一乘以 $W$，得到：

$$
\boxed{b_i=l_iW+(r_i-l_i)D}.
$$

这就是代码最后输出的式子。由于各项同时乘上相同的数，占比不会改变。

更具体地说：

$$
\sum_{i=1}^{n}b_i
=LW+WD
=200W>0,
$$

于是：

$$
100\frac{b_i}{\sum_{j=1}^{n}b_j}
=\frac{b_i}{2W}
=\frac{x_i}{2}
=p_i.
$$

因此，输出的整数数组恢复了我们构造的真实百分比，四舍五入后恰好得到输入。

例如 $a=[33,33,33]$，每个区间都是 $[65,67)$。此时 $L=195$、$W=6$、$D=5$，构造出的每个 $b_i$ 都是：

$$
65\times6+2\times5=400.
$$

三个数的真实占比均为 $33.\overline3\%$，四舍五入后都是 $33\%$。

### 数值范围与复杂度

每个区间长度最多为 $2$，所以 $W\le2n$。有解时，各项非负，并且：

$$
0\le b_i\le\sum_{j=1}^{n}b_j=200W\le400n.
$$

题目中 $n\le2\times10^5$，所以 $b_i\le8\times10^7<10^9$，满足输出限制。实现中用 long long 保存累加值和乘法结果。

每组数据只遍历数组两次，时间复杂度为 $O(n)$，空间复杂度为 $O(n)$。整个构造不需要浮点运算。

### 参考代码

下面保留原代码的构造方法，只去掉无关模板并整理命名。

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;

void solve() {
    int n;
    cin >> n;

    vector<ll> l(n), r(n);
    ll lef = 0, rig = 0, diff = 0;

    for (int i = 0; i < n; ++i) {
        ll a;
        cin >> a;
        l[i] = max(2 * a - 1, 0LL);
        r[i] = 2 * a + 1;
        lef += l[i];
        rig += r[i];
        diff += r[i] - l[i];
    }

    if (lef > 200 || rig <= 200) {
        cout << "No\n";
        return;
    }

    ll D = 200 - lef;
    cout << "Yes\n";
    for (int i = 0; i < n; ++i) {
        ll b = l[i] * diff + (r[i] - l[i]) * D;
        cout << b << (i + 1 == n ? '\n' : ' ');
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;
    while (t--) {
        solve();
    }
    return 0;
}
```
